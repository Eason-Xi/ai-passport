# 乐器节拍器 — FoloToy AI Passport

为 FoloToy AI Passport 打造的离线乐器节拍器，全中文界面，三个按键就能完成全部操作。
click 声按音频样本精确排布，长时间练习不漂移；屏幕上的节拍点与摆杆在声音真正从扬声器
发出的那一刻才点亮，看到的和听到的始终对齐。

## 快速上手

1. 把固件 `build/FoloToy-AI-Passport-full.bin` 刷入设备（见[刷写固件](#刷写固件)），开机直接进入节拍器。
2. 按 **UP / DOWN** 调速度，按住可快速连调；按 **OK** 开始（先倒数 3 秒）或停止。
3. **长按 OK** 打开设置，调拍号、细分、音色和音量；**双击 OK** 跟着音乐敲出速度。

## 功能

| 功能 | 说明 |
| --- | --- |
| 速度 | 30–250 BPM；按一下 ±1，按住加速连调（先逐个增减，约 2 秒后按 5 的倍数跳），松手立即停 |
| 拍号与重音 | 每小节 1–12 拍，首拍重音可开关；首拍节拍点为琥珀色 |
| 拍子细分 | 不细分 / 八分 / 三连音 / 十六分，细分音比正拍轻 |
| 开始倒数 | 按 OK 开始时屏幕显示 3、2、1，每秒一声提示音，第 3 秒结束时准时响起第一拍；倒数中再按 OK 取消；可在设置中关闭 |
| 敲击测速 | 跟着音乐按任意键，取最近至多 8 次间隔的平均值，停下 2.5 秒后自动应用 |
| 音色 | 电子音、木块、牛铃，全部由固件实时合成，每种都有重音 / 普通拍 / 细分三种力度 |
| 音量 | 0–10 档，0 档静音（静音时画面节拍照常） |
| 速度术语 | 按当前 BPM 显示意大利语术语与中文名，见下方对照表 |
| 掉电保存 | 所有设置自动保存，下次开机恢复 |
| 休眠与自动关机 | 停止后无操作：60 秒调暗 → 2 分钟熄屏 → 10 分钟自动关机；播放中不计时。熄屏时按任意键亮屏（这一下不触发功能），关机后按任意键开机 |
| 低电量保护 | 电量 ≤ 3% 时提示"电量过低"，3 秒后自动关机；接电脑 USB 或正在充电时不触发 |
| 电量 | 右上角显示电量，20% 及以下变红；读不到电量计时自动隐藏 |
| 离线 | 不使用 Wi-Fi 与蓝牙，固件中已关闭蓝牙 |

## 操作说明

### 按键

| 页面 | UP / DOWN | OK 单击 | OK 双击 | OK 长按 |
| --- | --- | --- | --- | --- |
| 主界面 | 按下 ±1 BPM；按住加速连调 | 开始（含倒数）/ 停止，倒数中按下即取消 | 进入敲击测速 | 打开设置 |
| 设置（浏览） | 上下移动选中行 | 编辑该行（"敲击测速"行直接进入测速） | — | 返回主界面 |
| 设置（编辑） | 改值（拍号、音量可按住连调） | 确认 | — | 返回主界面 |
| 敲击测速 | 任意键按下 = 敲一下 | （同样算敲一下） | — | 取消，不改速度 |

### 主界面

自上而下依次是：拍号与细分摘要、电量 → 速度术语 → 当前 BPM → 运行状态 → 节拍点（当前拍点亮）
→ 细分点（细分不为"不细分"时显示）→ 摆杆（每拍摆到一侧，与声音同步）→ 操作提示。

### 设置面板

从屏幕底部滑出，节拍器**不会停**，改动立即能听到；面板右上角的小灯随节拍闪烁。
可调项：拍号、首拍重音、细分、音色、音量、开始倒数，以及进入敲击测速的入口。

### 敲击测速

1. 主界面双击 OK，或在设置中选择"敲击测速"。进入时节拍器会暂停。
2. 跟着音乐按任意键，屏幕实时显示测得的 BPM 和已敲次数。
3. 至少敲 3 下后停手，2.5 秒后自动应用，显示"已设定"后返回原页面，并恢复原来的播放状态。
4. 不足 3 下且 6 秒没有再敲，会不改速度直接返回；随时长按 OK 取消。

### 休眠、关机与开机

- 节拍器停止后不操作：60 秒屏幕调暗，2 分钟熄屏，10 分钟自动关机；播放时不会休眠或关机。
- 熄屏或调暗时按任意键先亮屏，这一下不会改变速度或开始播放。
- 关机后按任意键即可开机，所有设置都会保留；也可以用设备的电源键。
- 电量过低时会显示提示并自动关机，请及时充电。

## 硬件要求

- FoloToy AI Passport：ESP32-C3、8 MB Flash、240 × 320 屏幕、UP / DOWN / OK 三键、ES8311 扬声器。
- 无需额外接线或外设。电量计不可用时只隐藏电量显示；音频初始化失败时顶栏提示"音频不可用"，
  节拍仍以画面显示。

## 刷写固件

交付固件为 `build/FoloToy-AI-Passport-full.bin`，是可从 `0x0` 直接烧录的合并镜像：

```bash
python -m esptool --chip esp32c3 -p <端口> -b 460800 write-flash 0x0 build/FoloToy-AI-Passport-full.bin
```

- macOS 上设备串口通常是 `/dev/cu.usbmodem*`；请使用支持数据传输的 USB 线。
- 合并镜像会覆盖 NVS，已保存的设置会恢复默认；不需要备份设备原有固件。
  详见[烧录说明](docs/development/engineering/firmware-layout.zh_CN.md#烧录与已存数据)。
- 想保留已保存的设置，可在源码目录用 `idf.py -p <端口> flash` 分段烧录。

## 从源码构建

需要 ESP-IDF 5.5.3（见[环境准备](docs/development/engineering/environment-setup.zh_CN.md)）。

```bash
source ~/esp/esp-idf-v5.5.3/export.sh
./tools/validate.sh            # 仓库检查 + 主机测试 + 固件构建 + 合并镜像校验
```

成功后生成 `build/FoloToy-AI-Passport-full.bin`，与之匹配的 ELF / MAP 调试文件归档在
`build/firmware/<full.bin 的 sha256>/`。只想跑主机测试时用 `./tools/validate.sh --static`（不需要 ESP-IDF）。

## 工作原理

- **样本即时钟**：音频任务（优先级 6）每 15 ms 渲染 240 个样本并写入 I2S。`main/mn_sched.c`
  用"整数商 + 余数累加"计算每个 tick 的样本位置，第 k 个 tick 恰好落在
  `floor(k × 16000 × 60 / (BPM × 细分))`，误差永远小于一个样本（62.5 µs），不会累积漂移。
- **声画同步**：开始时先写满整个 DMA 输出队列（6 × 240 样本 ≈ 90 ms）的静音，之后队列保持满载，
  每个 tick 的发声时刻就能由写入返回的时间推算出来。界面的 20 ms 定时器取出已到发声时刻的事件，
  这时才点亮节拍点、让摆锤闪光；摆杆按余弦运动，每个拍头到达一侧极点。
- **开始倒数**：同样按样本计时，倒数音落在第 0、1、2 秒，第 3 秒整响起第一拍；倒数中改速度不影响倒数时刻。
- **参数切换**：BPM 立即按新间隔重排；细分在下一拍拍头生效；拍数减少时在下一拍回到第 1 拍。
- **保存不打断声音**：写 Flash 会暂停 Cache、可能让音频断流，因此设置只在节拍器停止、
  最后一块声音播完、且最后一次修改已过 1.5 秒后才写入；运行中的修改在停止后保存。

### 修改界面文案

所有中文文案只能写在 `main/mn_strings.h`。改完后重新生成字体子集，否则 `validate.sh` 会报字体过期：

```bash
python3 tools/gen_metronome_fonts.py generate \
    --lv-font-conv <lv_font_conv 1.5.3 路径> --font <SourceHanSansSC-Regular.otf>
```

## 测试状态

- **主机测试**：`./tools/validate.sh --static` 覆盖节拍调度（7 种 BPM × 4 种细分各连续 1 小时零漂移、
  参数切换边界、分块无关）、音色合成（首尾归零、不削波、力度区分）、敲击测速、速度术语与布局、
  设置存档与损坏检测、页面状态机与四级省电、低电量判定、自动关机顺序约束，以及中文字形覆盖。
- **固件构建**：ESP-IDF 5.5.3 编译零警告，合并镜像校验通过。
- **真机**：节拍器主体功能已在 FoloToy AI Passport 上整体实测可用；休眠、自动关机、按键开机、低电量保护与开始倒数尚未真机验证。

## 已知限制

- 声画同步按"DMA 队列始终满载"推算发声时刻，残余偏差未做仪器测量；如有固定偏差，可调整
  `main/mn_ui.c` 中的 `LAG_COMP_US`。
- 音量档位与 codec 音量的对应关系（1 档 46% … 10 档 100%）未做响度测量，可在
  `main/mn_cfg.c` 的 `mn_cfg_volume_percent()` 中调整。
- 敲击测速受按键 5 ms 轮询影响，单次间隔约有 ±5 ms 抖动，平均后误差约 ±1 BPM。
- 三个按键共用一路 ADC，不支持组合键。
- "关机"是关闭各外设后进入深度睡眠，不是切断电源（电源由设备的独立电源键控制），仍有少量待机电流，未做测量。
- 关机后按键开机依靠按键节点的低电平唤醒；OK 键的电压余量最小，能否稳定唤醒需真机确认。
- 设备没有充电状态信号：接电脑 USB 时可直接识别；只接充电头时，按低电量期间电池电压是否上升来判断是否在充电。
